# Contributing to CraftRoster

Thanks for testing and contributing!

## Reporting bugs

Open an issue and include:

- WoW version/flavor (e.g., 3.3.5a)
- What you clicked / what you expected
- Any error text (use the beetle button in `/cr settings` to copy it)

## Pull requests

- Keep changes small and focused
- Test in-game before submitting
- Describe what you changed and why

## Code style

- Lua, 4-space tabs
- Keep the addon lightweight: no background polling or heavy loops
